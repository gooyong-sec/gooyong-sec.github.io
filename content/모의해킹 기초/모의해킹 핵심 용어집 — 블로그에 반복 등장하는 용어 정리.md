## 1. 네트워크·웹 기초

**클라이언트-서버 (Client-Server)**
서비스를 요청하는 쪽(클라이언트)과 요청을 받아 처리하는 쪽(서버)을 나눈 구조입니다. 웹 브라우저가 클라이언트, 웹사이트를 운영하는 컴퓨터가 서버입니다.
→ [[모의해킹 전에 알아야 할 IT 기초 — 클라이언트-서버, IP·포트, HTTP]], [[Java 웹 기초 1 — HTTP·웹 서버·WAS와 요청 처리 흐름]]

**IP 주소 (IP Address)**
인터넷에 연결된 각 장치를 구분하는 고유한 숫자 주소입니다. 건물의 번지수와 같은 역할을 합니다.
→ [[모의해킹 전에 알아야 할 IT 기초 — 클라이언트-서버, IP·포트, HTTP]], [[스코프와 교전규칙(RoE) — 모의해킹을 시작하기 전에 정해야 할 것들]]

**포트 (Port)**
같은 서버(같은 IP) 안에서 어떤 서비스로 연결할지 구분하는 번호입니다. 건물 안의 호실 번호와 같습니다.
→ [[모의해킹 전에 알아야 할 IT 기초 — 클라이언트-서버, IP·포트, HTTP]], [[체계적 서비스 열거 플레이북 — SMB, LDAP, SNMP, MSSQL, NFS 프로토콜별 체크리스트]]

**CIDR (Classless Inter-Domain Routing)**
`198.51.100.0/24`처럼 IP 주소 대역을 한 번에 표기하는 방식입니다. 모의해킹 스코프 문서에서 허용 대상 범위를 적을 때 자주 씁니다.
→ [[스코프와 교전규칙(RoE) — 모의해킹을 시작하기 전에 정해야 할 것들]], [[펜테스터를 위한 네트워크 피벗팅과 터널링 — SSH, Chisel, Ligolo-ng, Proxychains]]

**DNS (Domain Name System)**
`example.com` 같은 도메인 이름을 실제 IP 주소로 바꿔주는 인터넷의 전화번호부입니다.
→ [[모의해킹 전에 알아야 할 IT 기초 — 클라이언트-서버, IP·포트, HTTP]], [[Java 웹 기초 1 — HTTP·웹 서버·WAS와 요청 처리 흐름]]

**HTTP (HyperText Transfer Protocol)**
브라우저(클라이언트)와 서버가 요청·응답을 주고받을 때 쓰는 공통 약속(프로토콜)입니다.
→ [[모의해킹 전에 알아야 할 IT 기초 — 클라이언트-서버, IP·포트, HTTP]], [[웹 취약점 진단 기법 입문 — XXE, SSRF부터 SQLi, XSS까지]]

**API (Application Programming Interface)**
사람이 아니라 **프로그램끼리** 데이터를 주고받기 위해 정해둔 접점입니다. 브라우저용 홈페이지와 달리, 정해진 요청 형식을 보내면 정해진 형식의 응답(보통 JSON)이 돌아옵니다.
→ [[LLM 서비스와 클라우드 공격 경로 — 실무 진단 체크리스트]], [[웹 취약점 진단 기법 입문 — XXE, SSRF부터 SQLi, XSS까지]]

**TLS/SSL**
네트워크 통신 내용을 암호화해 중간에서 가로채도 읽을 수 없게 만드는 프로토콜입니다. `https://`의 자물쇠 표시가 이 암호화가 적용됐다는 뜻입니다.
→ [[Java 웹 기초 1 — HTTP·웹 서버·WAS와 요청 처리 흐름]], [[펜테스터를 위한 네트워크 피벗팅과 터널링 — SSH, Chisel, Ligolo-ng, Proxychains]]

**쿠키 (Cookie)**
서버가 브라우저에 저장해두도록 보내는 작은 데이터 조각으로, 로그인 상태를 유지하는 데 주로 쓰입니다.
→ [[모의해킹 전에 알아야 할 IT 기초 — 인증과 인가, 세션과 토큰]], [[Java 웹 기초 4 — Filter·Session과 인증·인가]], [[웹 취약점 진단 인증편 — 계정 잠금 우회부터 세션 하이재킹까지]]

**세션 (Session)**
로그인부터 로그아웃까지 사용자와 서버가 유지하는 하나의 상태 단위입니다. 보통 쿠키에 담긴 세션 ID로 식별합니다.
→ [[모의해킹 전에 알아야 할 IT 기초 — 인증과 인가, 세션과 토큰]], [[Java 웹 기초 4 — Filter·Session과 인증·인가]], [[웹 취약점 진단 인증편 — 계정 잠금 우회부터 세션 하이재킹까지]]

**프록시 (Proxy)**
클라이언트와 서버 사이에서 요청을 대신 전달해주는 중개 서버입니다. 모의해킹에서는 요청·응답을 가로채 조작하는 용도로 많이 씁니다(예: Burp Suite).
→ [[펜테스터를 위한 네트워크 피벗팅과 터널링 — SSH, Chisel, Ligolo-ng, Proxychains]], [[체계적 서비스 열거 플레이북 — SMB, LDAP, SNMP, MSSQL, NFS 프로토콜별 체크리스트]]

**방화벽 (Firewall)**
정해진 규칙에 따라 허용된 트래픽만 통과시키고 나머지는 막는 네트워크 관문입니다.
→ [[펜테스터를 위한 네트워크 피벗팅과 터널링 — SSH, Chisel, Ligolo-ng, Proxychains]], [[체계적 서비스 열거 플레이북 — SMB, LDAP, SNMP, MSSQL, NFS 프로토콜별 체크리스트]]

**VPN (Virtual Private Network)**
공용 네트워크 위에 암호화된 전용 통로를 만들어, 멀리 있어도 마치 같은 내부망에 있는 것처럼 접속하게 하는 기술입니다.
→ [[펜테스터를 위한 네트워크 피벗팅과 터널링 — SSH, Chisel, Ligolo-ng, Proxychains]], [[스코프와 교전규칙(RoE) — 모의해킹을 시작하기 전에 정해야 할 것들]]

**SSH (Secure Shell)**
원격 서버에 안전하게(암호화된 채널로) 접속해 명령을 실행할 수 있게 해주는 프로토콜입니다.
→ [[펜테스터를 위한 네트워크 피벗팅과 터널링 — SSH, Chisel, Ligolo-ng, Proxychains]], [[Linux 권한상승을 위한 OS 내부구조 — SUID, Capabilities, PATH, cron와 systemd]]

## 2. 모의해킹 공통 용어

**PTES (Penetration Testing Execution Standard)**
모의해킹을 사전 협의부터 보고까지 7단계로 표준화한 방법론입니다.
→ [[모의해킹 방법론 총정리 — PTES 7단계와 OWASP WSTG로 보는 진단 전체 지도]], [[스코프와 교전규칙(RoE) — 모의해킹을 시작하기 전에 정해야 할 것들]]

**OWASP (Open Worldwide Application Security Project)**
웹·모바일 보안 표준과 가이드를 만드는 비영리 기관 이름입니다. 그 자체는 도구가 아니라 "누가 만들었는지"를 가리키며, 실제 체크리스트는 아래 WSTG·MASVS 같은 개별 문서입니다.
→ [[모의해킹 방법론 총정리 — PTES 7단계와 OWASP WSTG로 보는 진단 전체 지도]], [[모바일 모의해킹 입문 — 환경 구축과 MASVS 체크리스트]]

**OWASP WSTG (Web Security Testing Guide)**
OWASP가 만든, 웹 애플리케이션을 어떤 항목으로 점검해야 하는지 정리한 테스트 가이드입니다.
→ [[모의해킹 방법론 총정리 — PTES 7단계와 OWASP WSTG로 보는 진단 전체 지도]], [[웹 취약점 진단 정찰편 — 공격표면 매핑과 헤더 기반 접근통제 우회]]

**RoE (Rules of Engagement, 교전규칙)**
모의해킹을 시작하기 전에 허용 범위, 시간, 금지 행위, 비상 연락망을 문서로 합의한 것입니다.
→ [[스코프와 교전규칙(RoE) — 모의해킹을 시작하기 전에 정해야 할 것들]]

**SOC (Security Operations Center)**
보안 이벤트를 상시 감시·분석·대응하는 조직입니다. 모의해킹 중에는 테스트 트래픽과 실제 공격을 구분(Deconfliction)해야 할 상대이기도 합니다.
→ [[스코프와 교전규칙(RoE) — 모의해킹을 시작하기 전에 정해야 할 것들]], [[모의해킹 vs 레드팀 vs 퍼플팀 — 목적·접근방식·산출물로 구분하기]]

**CVE (Common Vulnerabilities and Exposures)**
공개적으로 식별된 특정 소프트웨어 취약점마다 부여하는 고유 번호(예: `CVE-2024-XXXX`)입니다.
→ [[모의해킹 리포트 작성법 — 재현 가능한 증적과 경영진 요약 쓰기]], [[웹 취약점 진단 — 공급망·의존성 보안(SCA와 악성 패키지)]]

**CVSS (Common Vulnerability Scoring System)**
발견된 취약점의 심각도를 공통 기준에 따라 숫자 점수로 매기는 체계입니다.
→ [[모의해킹 리포트 작성법 — 재현 가능한 증적과 경영진 요약 쓰기]], [[모의해킹 vs 레드팀 vs 퍼플팀 — 목적·접근방식·산출물로 구분하기]]

**PoC (Proof of Concept)**
"이 취약점이 실제로 동작한다"는 것만 보여주기 위한 최소한의 예제 코드나 절차입니다. 실무 공격 도구처럼 다듬어지지 않은, 개념 검증용 샘플이라는 뜻입니다.
→ [[LLM·AI 서비스 CVE와 공개 PoC 카탈로그]], [[모의해킹 리포트 작성법 — 재현 가능한 증적과 경영진 요약 쓰기]]

**스캐닝 (Scanning)**
대상 서버의 열린 포트, 동작 중인 서비스와 버전을 탐지하는 사전 정찰 단계입니다.
→ [[체계적 서비스 열거 플레이북 — SMB, LDAP, SNMP, MSSQL, NFS 프로토콜별 체크리스트]], [[모의해킹 방법론 총정리 — PTES 7단계와 OWASP WSTG로 보는 진단 전체 지도]]

**열거 (Enumeration)**
스캐닝으로 찾아낸 서비스에서 계정 목록, 공유 폴더, 설정값 같은 구체적인 정보를 캐내는 단계입니다.
→ [[체계적 서비스 열거 플레이북 — SMB, LDAP, SNMP, MSSQL, NFS 프로토콜별 체크리스트]], [[스코프와 교전규칙(RoE) — 모의해킹을 시작하기 전에 정해야 할 것들]]

**피벗팅 (Pivoting)**
이미 장악한 시스템을 발판 삼아, 원래 직접 접근할 수 없던 내부망의 다른 시스템으로 이동하는 기법입니다.
→ [[펜테스터를 위한 네트워크 피벗팅과 터널링 — SSH, Chisel, Ligolo-ng, Proxychains]]

## 3. 취약점·공격 용어

**취약점 (Vulnerability)**
공격자가 악용할 수 있는 설계·구현상의 약점입니다. 모의해킹의 목표는 이것을 공격 전에 찾아내는 것입니다.
→ [[모의해킹 방법론 총정리 — PTES 7단계와 OWASP WSTG로 보는 진단 전체 지도]], [[웹 취약점 진단 기법 입문 — XXE, SSRF부터 SQLi, XSS까지]]

**익스플로잇 (Exploit)**
발견된 취약점을 실제로 악용해 의도되지 않은 동작을 일으키는 코드나 기법입니다.
→ [[클라우드 인프라 진단 — AWS IAM 권한상승 체인]], [[Linux 권한상승을 위한 OS 내부구조 — SUID, Capabilities, PATH, cron와 systemd]]

**페이로드 (Payload)**
공격 과정에서 대상 시스템에 실제로 전달·실행되는 코드나 데이터입니다.
→ [[웹 취약점 진단 — XSS 페이로드별 사용처와 목적]], [[Java 웹 기초 1 — HTTP·웹 서버·WAS와 요청 처리 흐름]]

**권한상승 (Privilege Escalation)**
낮은 권한 계정에서 관리자 권한처럼 더 높은 권한으로 올라가는 과정입니다.
→ [[모의해킹 전에 알아야 할 IT 기초 — 운영체제, 파일과 권한, 터미널]], [[Linux 권한상승을 위한 OS 내부구조 — SUID, Capabilities, PATH, cron와 systemd]], [[Windows 권한상승을 위한 OS 내부구조 — Access Token, UAC, 서비스 제어 관리자(SCM)]]

**자격증명 (Credential)**
계정 로그인에 쓰이는 ID·비밀번호, 토큰, 키처럼 신원을 증명하는 정보입니다.
→ [[펜테스터를 위한 네트워크 피벗팅과 터널링 — SSH, Chisel, Ligolo-ng, Proxychains]], [[클라우드 인프라 진단 — AWS IAM 권한상승 체인]]

**해시 (Hash)**
원본 데이터를 고정된 길이의 값으로 변환해, 그 값만 보고는 원본을 역산하기 어렵게 만든 결과값입니다. 비밀번호를 평문 그대로 저장하지 않고 해시로 저장하는 것이 대표적인 사용 예입니다.
→ [[공격 체인 이전의 AD 아키텍처 기초 — Kerberos, NTLM, DACL·ACE, GPO·SYSVOL, 도메인 트러스트]], [[윈도우 AD 침투 자격증명 피벗 권한상승 3가지 기법]]

**RCE (Remote Code Execution)**
공격자가 원격에서 대상 시스템에 임의의 명령을 실행할 수 있게 되는, 가장 심각한 수준의 취약점 유형입니다.
→ [[웹 취약점 진단 기법 입문 — XXE, SSRF부터 SQLi, XSS까지]], [[윈도우 AD 침투 자격증명 피벗 권한상승 3가지 기법]]

**C2 (Command and Control)**
공격자가 장악한 시스템을 원격으로 지휘·제어하기 위해 구축하는 서버 또는 통신 채널입니다.
→ [[펜테스터를 위한 네트워크 피벗팅과 터널링 — SSH, Chisel, Ligolo-ng, Proxychains]], [[Windows 권한상승을 위한 OS 내부구조 — Access Token, UAC, 서비스 제어 관리자(SCM)]]

## 4. 보안 운영·방어·클라우드 용어

**IAM (Identity and Access Management)**
클라우드나 시스템에서 "누가 어떤 자원에 어떤 권한으로 접근할 수 있는지"를 관리하는 체계입니다. 계정(자격증명)뿐 아니라 역할·정책까지 포함하는 더 큰 개념입니다.
→ [[클라우드 인프라 진단 — AWS IAM 권한상승 체인]], [[LLM 서비스와 클라우드 공격 경로 — 실무 진단 체크리스트]]

**AD (Active Directory)**
Windows 환경에서 사용자·컴퓨터·그룹의 계정과 권한을 한곳에서 관리하는 마이크로소프트의 디렉터리 서비스입니다. 회사의 "조직도 + 사원증 발급소"에 해당합니다.
→ [[공격 체인 이전의 AD 아키텍처 기초 — Kerberos, NTLM, DACL·ACE, GPO·SYSVOL, 도메인 트러스트]], [[윈도우 AD 침투 자격증명 피벗 권한상승 3가지 기법]]

**Kerberos**
AD 환경에서 한 번 인증받으면 그 "표(티켓)"로 여러 서비스에 재인증 없이 접근할 수 있게 해주는 인증 프로토콜입니다.
→ [[공격 체인 이전의 AD 아키텍처 기초 — Kerberos, NTLM, DACL·ACE, GPO·SYSVOL, 도메인 트러스트]], [[AD 환경 Kerberos 체인 공격 - 위임 남용과 토큰 가장]]

**OPSEC (Operations Security)**
공격자가 자신의 활동(공격 시각, 사용 IP, 실행한 명령어)을 방어팀에 들키지 않도록 숨기는 수준입니다. 모의해킹은 보통 낮고, 레드팀은 매우 높습니다.
→ [[모의해킹 vs 레드팀 vs 퍼플팀 — 목적·접근방식·산출물로 구분하기]]

**SIEM (Security Information and Event Management)**
여러 시스템의 로그와 보안 이벤트를 한곳에 모아 탐지 규칙으로 분석하는 보안 모니터링 시스템입니다.
→ [[모의해킹 vs 레드팀 vs 퍼플팀 — 목적·접근방식·산출물로 구분하기]]

**EDR (Endpoint Detection and Response)**
개별 PC·서버(엔드포인트)에서 벌어지는 행위를 감시해 악성 행위를 탐지·차단하는 보안 소프트웨어입니다. 파일 서명만 보는 백신(AV)보다 실제 행동 패턴을 봅니다.
→ [[윈도우 AD 침투 자격증명 피벗 권한상승 3가지 기법]], [[모의해킹 vs 레드팀 vs 퍼플팀 — 목적·접근방식·산출물로 구분하기]]

**ATT&CK (MITRE ATT&CK)**
공격자의 행동을 '정찰', '초기 접근', '권한상승' 같은 표준 기법 단위로 분류해둔 지식 체계입니다. 레드팀과 블루팀이 공격 단계를 같은 언어로 부르기 위해 공통으로 참조합니다.
→ [[모의해킹 vs 레드팀 vs 퍼플팀 — 목적·접근방식·산출물로 구분하기]], [[보안이슈 트래커 빌드 후기 — psv와 build.mjs로 서버 없는 정적 도구 만들기]]

**OIDC (OpenID Connect)**
"로그인 권한을 다른 서비스에 위임"하는 OAuth 위에, "이 사람이 누구인지(신원)"를 확인하는 기능을 얹은 프로토콜입니다. OAuth가 접근 권한 위임이라면, OIDC는 그 위에서의 신원 확인이라는 차이가 있습니다.
→ [[웹 취약점 진단 SSO편 — OAuth·OIDC 플로우 공격]], [[모바일 취약점 진단 — OAuth·PKCE 네이티브 플로우 공격]]
