# 보안 이슈 · MITRE ATT&CK 정리

**보는 법**: `index.html`을 더블클릭하면 브라우저에서 열린다. 서버가 필요 없다. 처음이라면 왼쪽 메뉴의 **처음이세요?** 부터 본다.

## 화면 구성

| 메뉴 | 내용 |
|------|------|
| 홈 | 최근 이슈를 쉽게 말하면, 통계 |
| 처음이세요? | 화면 읽는 법, 근거 표기, 원인 유형, ATT&CK 소개 |
| 사건 타임라인 | 41건, 연도·원인 유형·근거로 필터. 사건마다 쉽게 말하면 → 먼저 할 일 → 원인 → 침투 경로 → 조치 |
| 국내 소식 | 한국 사건(`지역: 한국`)과 국내 뉴스 브리핑 |

| 위협 행위자 · 일일 보고서 · 용어집 · 문서 | |

## 갱신

1. 사건을 `### [ID] 제목` + `> 날짜: … · 유형: … · 행위자: … · 지역: … · 근거: …` 형식으로 쓴다. 메타 줄 다음에 `**쉽게 말하면**: …`, `**먼저 할 일(초보용)**: …` 문단을 쓴다.
2. `ATTACK/매핑.psv`에 `사건ID|전술|기법|근거|설명` 행을, `분류.psv`에 원인 유형을 추가한다. 새 기법이면 `ATTACK/기법해설.psv`에도 쉬운 설명을 추가한다.
3. 한국 소식은 `국내뉴스.psv`에 한 줄 추가한다.
4. `node build.mjs` 실행. 누락·불일치는 경고로 알려 준다.

## 사건 한 건의 구성

쉽게 말하면 → 먼저 할 일 → 개요 → **왜 일어났나**(직접 원인 + 구조적 원인) → 침투 경로 → **어떻게 조치하나**(즉시·단기·장기·탐지) → 교훈.
근거 표기: 확인 / 보도 / 추정 / 주장. 조치는 이 문서의 권고이며 벤더 공식 지침이 우선한다. '먼저 할 일'은 시작점이지 전체 대응이 아니다.
