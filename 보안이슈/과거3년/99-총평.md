# 3년 총평 — 왜 계속 뚫리고, 무엇부터 막아야 하나

> 대상: 2023-10 ~ 2026-10 선정 사건(과거 3년 33건 + 일일 보고서 8건). **선정 사례의 공통점**이며 전체 공격의 통계가 아니다. 조치는 본 보고서의 권고, ATT&CK 완화(Mitigation) 이름·ID는 MITRE 공식 목록(v19.2)을 확인했다.

**공통 원칙**: (1) 모든 '즉시' 조치는 증거(로그·메모리·디스크·클라우드 감사 기록)를 보존한 뒤 수행한다. (2) 침해된 장비·계정에서 새 비밀을 발급하지 않는다(재탈취 위험). (3) 패치·MFA·백업 같은 통제는 이미 발급된 세션·토큰·키, 이미 설치된 지속성, 오염된 복구본을 해결하지 못하므로 **회수·무효화·검증**을 별도 완료 조건으로 둔다. (4) '구조적 원인'은 확인된 사실이 아니라 본 보고서의 분석이다.

## 2. 시간 순서로 본 변화 (선정 사례 기준)

- **2023~2024**: *엣지 장비 + 세션·자격 증명*. Citrix Bleed, Ivanti, PAN-OS가 VPN·방화벽을 열고, Okta·Snowflake·Change Healthcare는 로그인 쪽에서 뚫렸다. 공통점은 **MFA를 우회하거나 아예 없는 지점**.
- **2025**: *서드파티·SaaS·공급망과 한국의 기본기 부재*. tj-actions·Salesloft·Shai-Hulud가 연쇄 피해를 만들었고, SKT·KT·롯데카드·예스24·SGI·쿠팡은 **평문 비밀, 8년 미패치, 백업 연결, 키 미회수**처럼 기본기 문제가 드러났다.
- **2026**: *전화·AI 활용 사회공학과 파괴, 보안 도구 자체의 공급망*. ShinyHunters vishing, Stryker wipe, Trivy→Bitwarden 체인. 이어 2026-09~10에 Citrix·Cisco·FortiMail 같은 엣지 장비가 **다시** 제로데이로 나왔다.

## 4. 우선순위 (비용 대비 효과순)

1. **외부 노출 자산 목록과 축소**: 인터넷에서 보이는 관리면·VPN·MFT·ERP를 전부 찾아 꼭 필요한 것만 남긴다. 악용 확인 즉시 격리한다.
2. **MFA 예외 0건 + 관리자는 피싱 저항 MFA**: 테스트·레거시·협력사·SaaS 포함.
3. **패치 SLA와 "패치 후 회수"**: 악용 확인 취약점은 일 단위. 패치 뒤에는 세션·키·자격 증명을 반드시 교체한다.
4. **오프라인·불변 백업과 복구 훈련**: 백업 자격 증명을 분리하고 복구 시간을 실제로 측정한다.
5. **비밀·키 관리**: KMS·HSM, 수명 단축, 퇴사·계약 종료 시 회수 체크리스트, 지원·티켓에 비밀 금지.
6. **서드파티·CI 통제**: 연동 토큰 최소 권한·IP 제한, 의존성·Action SHA 고정.
7. **탐지**: 엣지·장비 로그 외부 보존, 웹셸·대량 외부 전송·관리 콘솔 대량 명령 경보.
8. **사람 절차**: 헬프데스크 콜백 본인 확인, 전화 기반 사칭 교육.
