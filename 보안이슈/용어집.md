# 보안 용어집 (초보용)

> 자동 생성. 원본은 `용어집.psv`. 보고서와 화면에서 이 용어가 처음 나오면 밑줄로 표시되고, 마우스를 올리면 뜻이 보인다.

| 용어 | 쉬운 설명 |
|------|------|
| CVE | 취약점에 붙는 공식 번호표(예: CVE-2026-1234). 같은 결함을 모두가 같은 이름으로 부르게 해 준다. |
| CVSS | 취약점의 위험도를 0~10점으로 매긴 점수. 높을수록 위험하다. |
| KEV | 미국 CISA가 '실제로 악용되고 있다'고 확인한 취약점 목록. 여기 오르면 서둘러 패치해야 한다. |
| 제로데이 | 제조사가 아직 모르거나 아직 패치가 없는 취약점. 이를 이용한 공격을 '제로데이 공격'이라 한다(보도에서는 '이미 공격에 쓰이는 미패치 취약점'을 뜻하는 경우가 많다). |
| 취약점 | 소프트웨어·장비의 보안 결함. 공격자가 이를 이용해 들어온다. |
| 패치 | 결함을 고치는 업데이트. |
| RCE | 원격 코드 실행. 공격자가 멀리서 상대 서버에 명령을 실행시키는 것으로 가장 위험한 유형 중 하나다. |
| 인증 우회 | 로그인 확인을 건너뛰고 들어가는 결함. |
| 웹셸 | 웹서버에 심어 두는 악성 파일. 공격자가 인터넷으로 접속해 서버에 명령을 내리는 '뒷문'이다. |
| 백도어 | 정상 로그인 없이 다시 들어올 수 있게 숨겨 둔 통로. |
| 랜섬웨어 | 파일을 암호화해 못 쓰게 만든 뒤, 풀어 주는 대가로 돈을 요구하는 악성코드. |
| 와이퍼 | 돈 요구 없이 데이터를 그냥 지워 버리는 파괴형 악성코드. |
| 인포스틸러 | PC에서 비밀번호·쿠키 등을 훔치는 악성코드. |
| 피싱 | 가짜 메일·사이트로 속여 정보를 빼내는 수법. |
| vishing | 전화로 속여 정보를 빼내는 수법(음성 피싱). |
| 사회공학 | 기술이 아니라 사람을 속여 정보를 얻는 공격. |
| MFA | 다중 인증. 비밀번호(아는 것)에 더해 휴대전화·보안키(가진 것)나 지문(신체 특징)처럼 서로 다른 종류를 함께 확인한다. 문자 코드는 가로채일 수 있어 방식에 따라 강도가 다르다. |
| FIDO2 | 비밀번호·코드를 입력하지 않고 보안키·기기 인증을 쓰는 방식. 등록된 사이트인지 확인해 인증하므로 가짜 로그인 사이트에 강하다. 기기 감염이나 로그인 뒤의 세션 탈취까지 막아 주지는 않는다. |
| 패스키 | FIDO2 기반의 비밀번호 없는 로그인. 지문·얼굴 등으로 인증한다. |
| SSO | 한 번 로그인하면 여러 서비스에 같이 접속되는 통합 로그인. |
| IdP | SSO 같은 로그인을 대신 확인해 주는 서비스(예: Okta, Entra ID). |
| OAuth | 앱이 비밀번호 없이 다른 서비스에 접속하도록 허락해 주는 방식. 허락의 증표가 '토큰'이다. |
| 토큰 | 로그인 상태나 접근 권한을 나타내는 값. 일부는 유출되면 유효기간과 권한 범위 안에서 비밀번호 없이도 악용될 수 있다. |
| 세션 하이재킹 | 훔친 로그인 상태(쿠키·토큰)로 그 사람인 척 접속하는 것. |
| 세션 | 로그인한 뒤 이어지는 접속 상태. |
| 쿠키 | 웹사이트가 로그인 상태 등을 기억하려고 브라우저에 저장하는 작은 정보. |
| 자격 증명 | 아이디·비밀번호·토큰·키처럼 신원을 증명하는 정보. |
| 패스워드 스프레이 | 흔한 비밀번호 몇 개를 수많은 계정에 돌려 가며 시도하는 공격. |
| 무차별 대입 | 비밀번호를 계속 바꿔 가며 맞을 때까지 시도하는 공격. |
| EDR | PC·서버에서 수상한 행동을 감시하는 보안 프로그램. |
| WAF | 웹사이트 앞에서 공격성 요청을 걸러 주는 웹 방화벽. |
| VPN | 바깥에서 회사 내부망에 안전하게 접속하게 해 주는 통로. |
| 방화벽 | 네트워크 출입을 규칙으로 막고 허용하는 장비. |
| 엣지 장비 | 회사 네트워크와 인터넷의 경계에 있는 장비(VPN·방화벽·메일 게이트웨이 등). |
| ERP | 회계·인사·재고 같은 회사 핵심 업무를 관리하는 시스템. |
| MFT | 기업이 큰 파일을 안전하게 주고받게 해 주는 파일 전송 소프트웨어. |
| SaaS | 설치 없이 웹으로 쓰는 서비스(예: Salesforce, Slack). |
| 공급망 공격 | 고객이 쓰는 소프트웨어·협력사를 먼저 뚫어 그 고객 모두를 노리는 공격. |
| SBOM | 소프트웨어에 어떤 부품(라이브러리)이 들어 있는지 적은 목록. |
| CI/CD | 코드를 자동으로 빌드·시험·배포하는 개발 자동화 과정. |
| 의존성 | 내 프로그램이 가져다 쓰는 외부 라이브러리·패키지. |
| 서명 키 | 로그인 토큰이 진짜임을 보증하는 비밀 도장. 유출되면 가짜 토큰을 만들 수 있다. |
| KMS | 암호 키를 안전하게 보관·관리하는 전용 서비스. |
| HSM | 키가 장치 밖으로 나가지 않게 보관하는 전용 보안 장치. |
| 불변 백업 | 정해진 기간 동안 수정·삭제를 막아 둔 백업. 별도 관리 권한과 복구 훈련이 함께 필요하고, 오염된 데이터를 되돌려 주지는 못한다. |
| 헬프데스크 | 직원·고객의 문의를 받아 계정 문제 등을 처리하는 지원 창구. |
| 횡적 이동 | 한 시스템에 들어온 뒤 내부의 다른 시스템으로 옮겨 가는 것. |
| 지속성 | 재부팅·비밀번호 변경 뒤에도 침입 상태를 유지하는 것. |
| 권한 상승 | 일반 권한에서 관리자 같은 높은 권한을 얻는 것. |
| 터널링 | 허용된 통신 안에 다른 통신을 숨겨 보내 방화벽을 통과하는 기법. |
| 프록시 | 중간에서 통신을 대신 전달해 주는 서버. 공격자는 출처를 숨기는 데 쓴다. |
| C2 | 공격자가 감염된 기기를 원격으로 조종하는 연결(명령·제어). |
| IOC | 침해 흔적을 알려 주는 단서(악성 IP, 파일 이름 등). |
| APT | 정부 지원 등으로 장기간·치밀하게 공격하는 조직. |
| 포렌식 | 침해 증거를 보존·분석해 무슨 일이 있었는지 밝히는 조사. |
| 최소 권한 | 꼭 필요한 권한만 주는 원칙. |
| PAM | 관리자 같은 높은 권한 계정을 별도로 통제·기록하는 관리 방식. |
| 조건부 접근 | 기기·위치·위험도에 따라 로그인을 허용하거나 막는 정책. |
| ESXi | VMware의 가상 서버 운영 소프트웨어. 한 대에 서버 수십 개가 올라간다. |
| Intune | 마이크로소프트의 기기 관리 서비스. 원격 초기화 같은 기능이 있다. |
| MDM | 회사가 직원 스마트폰·PC를 원격으로 관리하는 방식. |
| 역직렬화 | 전달받은 데이터를 프로그램 객체로 되돌리는 처리. 신뢰할 수 없는 데이터를 위험한 방식으로 복원하면 구현에 따라 코드 실행 같은 문제가 생길 수 있다. |
| SHA 고정 | 검토한 특정 코드를 고유 번호(SHA)로 지정해 몰래 바뀌는 것을 막는 방법. 악성 코드를 고정하면 그대로 실행되므로 코드가 안전하다는 보증은 아니다. |
| LFI | 서버에 있는 파일을 프로그램이 불러오게 만드는 결함(로컬 파일 포함). |
| 정규화 | URL 같은 입력을 하나의 표준 형태로 바꾸는 처리. 검사 단계와 처리 단계가 다르게 해석하면 우회가 생긴다. |
| NTDS.dit | 윈도 도메인의 모든 계정 비밀번호 정보가 들어 있는 파일. |
| USIM | 휴대폰 가입자를 식별·인증하는 칩(유심). |
| 펨토셀 | 집·사무실용 초소형 기지국. |
| TACACS+ | 네트워크 장비 관리자 로그인을 확인하는 프로토콜. |
| DTLS | UDP 통신을 암호화하는 방식(VPN 등에서 쓴다). |
| BPFDoor | 특정 통신 신호로 깨우는 방식으로 숨어 있는 리눅스 백도어. |
| 오픈소스 | 누구나 코드를 보고 쓸 수 있게 공개된 소프트웨어. |
| KISA | 한국인터넷진흥원. 한국의 인터넷·보안 지원 기관. |
| CISA | 미국 사이버보안·인프라보안국. |
| ATT&CK | MITRE가 만든 '공격자가 쓰는 행동 사전'. 전술(목표)과 기법(방법)으로 정리한다. |
| SAML | 회사 로그인(SSO)에서 "이 사람이 맞다"는 증명서를 주고받는 표준 방식. 이 방식을 처리하는 장비 부분의 결함이 문제가 된 사례가 있다. |
| 서비스 거부(DoS) | 장비나 서비스를 과부하·오류로 멈추게 해 정상 사용을 막는 공격. 데이터가 새는 것과는 다른 피해다. |
| 접속키 | 서비스·서버에 접속할 때 쓰는 비밀 열쇠(API 키·액세스 키 등). 코드나 개발 PC에 방치하면 유출 위험이 크다. |
| AI 에이전트 | 스스로 판단해 여러 단계의 작업을 자동으로 이어서 수행하는 AI. 공격에 쓰이면 사람보다 훨씬 빠르게 시도할 수 있다. |
| ARTEX | 오픈소스 LLM 기반 자율 침투 테스트 도구(보도). 방어 점검용이지만 공격에도 쓸 수 있고, 금융권 사건에서 사용 여부는 확정되지 않았다. |
| 민관합동조사단 | 정부와 민간 전문가가 함께 침해사고의 원인과 피해를 조사하는 팀. |
| SQL 삽입 | 입력칸에 데이터베이스 명령을 끼워 넣어 원래 허용되지 않은 정보를 읽거나 바꾸는 공격. 입력값을 제대로 검사하지 않을 때 가능하다. |
| 핫월렛 | 거래소가 즉시 이체할 수 있도록 인터넷에 연결해 둔 가상자산 지갑. 편리하지만 침해되면 바로 자산이 빠져나갈 수 있다. |
