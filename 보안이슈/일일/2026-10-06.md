## 2. 이슈별 분석

### [D20261006-sonicwall-sma] SonicWall SMA1000 Work Place 사전 인증 SSRF (CVE-2026-102255)
> 날짜: 2026-10-06 · 유형: 엣지 장비 취약점 · 행위자: 미귀속 · 지역: 글로벌 · 근거: 확인

**쉽게 말하면**: 원격 접속 장비인 SonicWall SMA1000 시리즈의 사용자 포털(Work Place) 인터페이스에서 로그인하지 않은 외부 공격자가 장비로 하여금 내부 기능에 요청을 보내게 만들고 비인가 작업을 수행할 수 있는 최고 위험도(CVSS 10.0) 결함이 공개됐습니다.

**먼저 할 일(초보용)**: SonicWall SMA1000 장비를 운영 중이라면 벤더 권고에 따른 최신 패치(12.4.3-03312 이상)를 즉시 적용하고, Work Place 포털과 관리 인터페이스의 불필요한 외부 노출을 차단하세요.

**개요**: SonicWall이 SMA1000(Secure Mobile Access) 어플라이언스의 Work Place 웹 인터페이스에서 발생하는 사전 인증 서버 측 요청 위조(SSRF) 및 대체 경로 접근 취약점(CVE-2026-102255, CVSS v3.1 10.0)을 공개했다. 인증되지 않은 원격 공격자가 조작된 요청을 보내 어플라이언스 내부 서비스와 통신하거나 비인가 동작을 유발할 수 있다.

**왜 일어났나**
- 직접 원인 [확인]: Work Place 인터페이스의 요청 경로 처리에서 의도치 않은 대체 경로(alternate path)를 통한 내부 요청 전달을 차단하지 못한 결함(CWE-918, CWE-424).
- 구조적 원인 [추정]: 원격 접속(VPN) 장비의 웹 포털이 외부 인터넷에 직접 노출되는 구조에서, 프록시·내부 API 호출 경계의 인증 전 입력 검증이 미흡할 경우 단일 결함이 장비 전체 위험으로 직결된다.

**침투 경로 [추정]**: 외부에 노출된 SMA1000 Work Place 포털에 조작된 사전 인증 요청 전송 → 장비 내부 서비스로 SSRF 발생 → 비인가 내부 기능 호출.

**어떻게 조치하나**
- 즉시: 증거(접근 로그·설정) 보존 후 SonicWall 공식 권고에 따른 최신 펌웨어/핫픽스 즉시 적용.
- 단기: Work Place 및 관리 콘솔의 비정상 요청 로그 점검, 의심 징후 발견 시 세션 초기화 및 자격 증명 재발급.
- 장기: 경계 장비 관리 인터페이스 인터넷 노출 차단 및 접근 IP 제한.
- 탐지: Work Place 엔드포인트에 대한 비정상 경로·프록시성 요청 패턴 모니터링.

**교훈**: SMA1000 제품군은 올해(CVE-2026-15409 등) 반복적으로 SSRF·인증 우회 결함이 발견되고 있어, 패치 적용뿐 아니라 노출 면적 자체를 줄여야 한다.
