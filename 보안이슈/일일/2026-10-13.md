## 2. 이슈별 분석

### [D20261013-ivanti] Ivanti Connect Secure 인증 우회 제로데이 — 루트 권한까지 체인 공격
> 날짜: 2026-10-13 · 유형: 노출 VPN 장비 취약점 · 행위자: UTA0576(Volexity 명명, 보도) · 지역: 글로벌 · 근거: 확인

**쉽게 말하면**: 회사 직원들이 외부에서 사내망에 접속할 때 쓰는 Ivanti VPN 장비에 로그인 절차를 건너뛸 수 있는 결함이 있고, 공격자들이 이미 10월 초부터 이를 실제로 쓰고 있었습니다. 더 나쁜 건 이 결함 하나만으로 끝나지 않고 아직 패치 안 된 또 다른 결함과 엮어서 장비의 최고 권한(루트)까지 올라갔다는 점입니다.

**먼저 할 일(초보용)**: 담당자는 Ivanti Connect Secure를 쓰는지 확인하고 Ivanti 공지의 수정 버전(ICS 22.8R2.5, 25.1.3.0, 25.1.3.1, 25.1.1.2 등, 계열별로 다르므로 공지 확인)으로 즉시 올리세요. 이미 뚫렸을 가능성이 있으니 패치만으로 끝내지 말고 계정 비밀번호, LAPS 비밀번호, BitLocker 복구 키 등 장비가 알고 있던 비밀 값을 깨끗한 환경에서 다시 발급하세요. 장비에서 바로 새 비밀번호를 만들지 마세요.

**개요**: CISA KEV 직접 확인: CVE-2026-104935, 'Ivanti Connect Secure 스푸핑에 의한 인증 우회 취약점', 2026-10-13 등재, 기한 10/16, 랜섬웨어 사용 '알 수 없음'. Ivanti는 같은 날 공지에서 CVSS 8.6으로 평가하고 "제한적인 실악용을 인지하고 있다"고 밝혔다(보도, 원문은 직접 열람하지 못함). 영향 버전은 ICS 22.8R2.4 이하, 25.1.2.2 이하, 25.1.1.1 이하. 보안업체 Volexity는 자사가 UTA0576으로 명명한 공격자가 이 인증 우회에 원격코드실행·별도의 권한상승 결함을 체인으로 엮어 완전히 패치된 장비에서도 루트 권한을 얻었다고 보도됐다. 권한상승 결함은 이번 보도 시점 기준 아직 패치되지 않았다고 전해진다. watchTowr는 조작된 'X-DSCGI-PATH' 헤더 하나로 인증을 우회할 수 있다고 분석했다(보도). 공격 시작 시점은 보도마다 달라 Volexity는 10월 초(일부 보도는 10/1, 다른 보도는 10/3)부터로 추정한다.

**왜 일어났나**
- 직접 원인 [확인: Ivanti·CISA]: 인증 절차를 스푸핑으로 우회하는 결함(CVE-2026-104935). 상세 코드 경로는 공개되지 않았다.
- 구조적 원인 [추정]: VPN 장비가 인터넷에 직접 노출되고, 하나의 결함이 다른 미패치 결함과 체인되면 완전 패치된 장비도 뚫릴 수 있는 구조적 위험(분석이며 확인된 사실 아님).

**침투 경로 [보도 범위]**: 조작된 요청으로 인증 우회(CVE-2026-104935) → 별도 RCE·권한상승 결함 체인 → 루트 권한 획득 → 자격 증명·AD 데이터·LAPS 비밀번호·BitLocker 복구 키 수집(보도, Volexity). 이후 횡적 이동·유출 여부는 공개되지 않았다.

**어떻게 조치하나**
- 즉시: 증거(장비 로그·설정)를 보존하고 수정 버전으로 올린다. 패치를 미루지 않는다.
- 단기: 이미 침해됐을 가능성을 전제로 장비에 저장·연동된 자격증명(LAPS 비밀번호, BitLocker 복구 키, 연동 계정)을 깨끗한 환경에서 교체한다. AD 쪽에서 비정상 로그인·권한 변경을 점검한다.
- 장기: 권한상승 결함의 Ivanti 패치가 나오면 즉시 적용. VPN 장비 관리면 노출 축소, 다중 인증 강화.
- 탐지: 장비의 비정상 인증 요청(조작된 헤더 등), 이후 AD·LAPS·BitLocker 관련 조회 행위.

**교훈**: 패치 하나로 안전해지지 않는다. 공격자는 패치된 결함과 미패치 결함을 엮어서 들어온다.

## 3. Microsoft 10월 정기 패치(Patch Tuesday) — 실악용 제로데이 1건 포함

> 10/12 보고서에서 "10/13 예정, 공개 전"으로 남겨 둔 건의 후속.

**쉽게 말하면**: 매달 둘째 화요일에 나오는 마이크로소프트 보안 패치가 이번 달엔 역대 최대 규모로 나왔습니다. 그중 하나는 이미 실제 공격에 쓰이고 있었습니다.

**개요**: BleepingComputer·SecurityWeek 등 보도에 따르면(원문은 직접 열람하지 못함) 이번 달 패치는 역대 최대 규모이며 매체별로 1,407~1,415건으로 숫자가 엇갈린다(합산 기준이 달라 생기는 차이로 보이며 단정하지 않는다). 제로데이 3건:
- **CVE-2026-96951** (Windows Shell, CVSS 8.8): Mark of the Web(인터넷에서 받은 파일임을 표시해 경고를 띄우는 보호 기능) 우회. Microsoft가 실제 악용을 확인했고 CISA가 같은 날(10/13) KEV에 등재했다(기한 10/16). 메일·메신저·협업 도구로 조작된 파일을 전달해 열게 하는 방식으로 알려졌다(보도, 사용자 상호작용 필요).
- **CVE-2026-108398** (.NET Framework 보안 기능 우회): Google Project Zero의 James Forshaw가 발견, 공개는 됐지만 실악용 보고는 없다(보도).
- **CVE-2026-92707** (MessagePack-CSharp 서비스 거부): 공개됐지만 실악용 보고는 없다(보도).

그 외 눈에 띄는 항목(모두 보도 기준, CISA KEV 등재는 아님): CVE-2026-70229(Active Directory Domain Services RCE), CVE-2026-77900(Azure App Service RCE), CVE-2026-96222·CVE-2026-108131(AD FS 스푸핑). 이번 달로 Windows 11 24H2 Home/Pro, Windows 10 Enterprise LTSB 2016의 보안 업데이트가 종료됐다(보도).

**먼저 할 일(초보용)**: Windows를 쓰는 조직은 이번 달 패치, 특히 Windows Shell 결함(CVE-2026-96951)부터 적용하세요. 아직 Windows 10 LTSB 2016이나 Windows 11 24H2 Home/Pro를 쓴다면 지원 종료 여부를 확인하고 전환 계획을 세우세요.

## 4. MITRE ATT&CK v20.0 공개 (2026-10-13)

공식 사이트(attack.mitre.org) 확인 결과 **ATT&CK Enterprise v20.0이 2026-10-13 공개**됐다. 새 전술 신설은 없고, 주요 변화는: AI 관련 신규 기법 9개(AI-Enabled Exfiltration, Direct/Indirect Prompt Injection, Anti-Automation Evasion, Impair Autonomous Defenses, AI Result Poisoning, Steal Application Specific Passwords 등), ICS 쪽 신규 기법(Command and Scripting Interpreter 하위기법 등), 신규 캠페인(2026년 미국 상수도 시설 공격·멕시코 정부 인프라 AI 지원 침해) 추가. 이 저장소(`ATTACK/_catalog.psv`)는 아직 v19.2 기준이며, v20 반영(신규 기법 목록 갱신·기존 매핑 재검토)은 규모가 커서 이번 일일 보고서 범위를 벗어난다. 별도 작업으로 남겨 둔다.

## 7. 검증 수준과 한계

- KEV 10/13 등재 2건(Ivanti, Windows Shell)은 CISA JSON 피드를 직접 받아 `dateAdded` 필드로 확인했다.
- Ivanti의 CVSS 점수·영향 버전·Volexity의 UTA0576 분석은 모두 2차 보도 기준이며 Ivanti·Volexity 원문은 직접 열람하지 못했다. 공격 시작 시점(10/1 vs 10/3)은 보도마다 다르다.
- Microsoft 10월 패치 총 건수는 매체별로 1,407~1,415건으로 엇갈려 하나로 확정하지 않았다. Microsoft 공식 보안 업데이트 가이드 원문은 직접 열람하지 못했다.
- ATT&CK v20.0 공개는 공식 사이트(attack.mitre.org/resources/updates/)에서 직접 확인했다.
- 국내: 금융·통신·이커머스·공공·교육·의료 질의를 했으나 10/13 당일 신규 대형 사건은 찾지 못했다. 국정감사 관련 사과·증인 채택 보도는 모두 10/8 발생분이 10/13 전후에도 재인용되는 수준이었다.
- GPT(Codex) 검토는 이 보고서 중 사실관계가 가장 많은 Ivanti 항목을 포함해 실시했다(출처 미표기 주장, 내부 불일치 여부 점검).
- **중복 작성 안내**: 이 보고서 작성 시점에 [10-17 보고서](2026-10-17.md)가 이미 존재하며, 10-12 이후 공백을 자체적으로 메운다는 전제로 Ivanti·Microsoft 패치 건을 다시 다루고 있다(해당 보고서는 10-13~16 구간에 일일 보고서가 없다고 전제하고 작성됨). 두 보고서의 날짜(KEV `dateAdded` 기준 10/13)와 내용이 겹치므로, 정리자는 추후 한쪽으로 통합하거나 상호 참조로 바꾸는 것을 검토해야 한다.
